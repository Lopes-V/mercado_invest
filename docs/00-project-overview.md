# Project Overview

## Problema
Acompanhar manualmente mercado, carteira e oportunidades demanda tempo e
dificulta manter histórico das decisões.

## Objetivo
Construir um sistema pessoal automatizado de apoio à decisão financeira.

## Usuário inicial
Um único usuário autorizado pelo Telegram.

## Objetivos principais
- Coletar mercado automaticamente.
- Armazenar histórico.
- Acompanhar carteira.
- Detectar situações relevantes.
- Utilizar IA para interpretar dados.
- Enviar alertas seletivos.
- Registrar decisões e resultados.

## Fora do escopo inicial
- Compra automática.
- Venda automática.
- Gestão de dinheiro de terceiros.
- Mercado estrangeiro na V1.

## Visão futura
- Mercado americano.
- Multi-moeda.
- Mais classes de ativos.
- Paper Trading.
- Backtesting avançado.

## Princípios
- Dados primeiro.
- IA não é fonte de verdade.
- Toda decisão deve ser auditável.
- Falha segura.
- Global-ready, Brazil-first.
