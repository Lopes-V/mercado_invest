# Telegram Bot

## Segurança
Somente Telegram User IDs autorizados podem utilizar comandos privados.

## Comandos

### /start
Apresenta o bot.

### /help
Lista comandos.

### /status
Exibe saúde do sistema.

### /mercado
Resumo do mercado.

### /analisar <ativo>
Solicita análise.

Exemplo:
/analisar PETR4

### /carteira
Exibe carteira.

### /oportunidades
Lista oportunidades detectadas.

### /alertas
Consulta alertas.

### /logs
Logs recentes.

### /performance
Performance das análises anteriores.

## Erros

Ativo inexistente:
"Ativo não encontrado."

Dados desatualizados:
"Não existem dados suficientemente recentes para análise."

Serviço indisponível:
"Análise indisponível no momento."
